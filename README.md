# Younot releases

This repository hosts unsigned Younot desktop installers and their SHA-256 checksums.

Younot is based on [SiYuan](https://github.com/siyuan-note/siyuan) and is licensed under the GNU Affero General Public License v3.0. Each release includes the exact corresponding source archive used to produce its installers.

Installers and source archives are published through the [Releases](https://github.com/AntonAlekseevich93/younot-releases/releases) page. Verify a downloaded installer against the accompanying `SHA256SUMS.txt` before installation.

The macOS application is intentionally distributed without an Apple Developer ID signature. On first launch, right-click Younot in Finder, choose **Open**, and confirm the system prompt.
